Questions fréquentes

Comment supprimer mon compte ?

Dans l'application : Profil → Supprimer mon compte. Deux confirmations vous sont demandées, puis tout est effacé — profil, dégustations, photos, commentaires, cave, abonnements. C'est immédiat et irréversible ; aucune demande par e-mail n'est nécessaire.

Comment signaler ou bloquer quelqu'un ?

Sur une dégustation ou un commentaire, touchez le bouton ⋯ ; sur un profil, utilisez Signaler ou Bloquer sous le bouton d'abonnement. Un blocage est réciproque : vous ne verrez plus rien l'un de l'autre, ni dégustations, ni commentaires, ni profil. Vous pouvez revenir dessus à tout moment depuis Profil → Personnes bloquées.

Les signalements sont examinés sous vingt-quatre heures. Le contenu signalé est conservé le temps de l'examen, même si son auteur l'efface entre-temps.

Qui voit mes dégustations ?

Vous choisissez à chaque fois : publique, réservée à un groupe, ou strictement privée. Votre cave, elle, n'est jamais visible par personne d'autre que vous.

J'ai oublié mon mot de passe

Sur l'écran de connexion, touchez Mot de passe oublié ?. Un code à six chiffres vous est envoyé par e-mail ; vous le saisissez dans l'application et choisissez aussitôt un nouveau mot de passe. Si vous vous connectez avec Apple, vous n'avez pas de mot de passe à retenir.

Je ne reçois pas les notifications

Vérifiez que vous les avez autorisées dans Réglages → MaGrappe → Notifications sur votre iPhone. MaGrappe n'envoie de notification que lorsque quelqu'un commente une de vos dégustations — jamais de message promotionnel.

Un vin est introuvable dans la recherche

Vous pouvez toujours le saisir à la main : renseignez le nom, le producteur et le millésime, et la dégustation s'enregistre normalement.
